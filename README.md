# 📰 NewsAdda

NewsAdda is a modern and responsive news web application built using React.js. It provides users with real-time news updates across multiple categories, including Business, Entertainment, Health, Science, Sports, and Technology.

## 🚀 Features

* Real-time news updates using News API
* Category-based news browsing
* Keyword-based news search
* Save and Like news articles
* Share news with others
* Responsive design for desktop and mobile devices
* Interactive dashboard with useful information
* Smooth and user-friendly interface

## 🛠️ Technologies Used

* React.js
* JavaScript (ES6+)
* HTML5
* CSS3
* Bootstrap
* React Router
* REST APIs
* Local Storage

## 📱 Responsive Design

The application is fully responsive and optimized for desktop, tablet, and mobile devices to ensure a seamless user experience.

## 🎯 Purpose

The goal of NewsAdda is to provide a simple, fast, and user-friendly platform where users can explore the latest news, search topics of interest, and manage their favorite articles.
